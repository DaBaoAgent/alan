# 封面 / 发布信息流（即梦图生图版）

2026-09 从 AutoYY 移植（对应 AutoYY 的 build_topic_covers_from_video.py + gen_jimeng_cover_prompts.py +
validate_publication_info.py），按艾伦频道标准改造：**不本地合成封面图**，
改为「选帧底图 + 即梦图生图提示词」，由用户到即梦出图。

## 封面标准（用户 2026-09-19 定版）

- 主体：**身材傲人 / 金发碧眼的女主角**（从原片里选最有女主感的帧做底图，能露身材/颜值优先）
- 文字：**只要一个大大的手写体电影名**做封面字幕，画面里不出现任何其他文字
- 标题字体与颜色（2026-09-19 用户定版）：**手写软笔笔刷字**（笔画偏粗、顿笔出锋、字形活泼有冲击力、带飞白毛边颗粒），**鲜红色字身 + 细黑色描边**；无渐变无金属光泽；参考图由用户提供（先后两版参考图，以第二版为准）
- 比例：3:4 竖版 + 4:3 横版（提示词一段一版），即 2 张封面
- 底图要求：人物有脸 + 有姿态、尽量亮/清晰/少杂物；死黑、运动模糊帧基本放弃

## 流程

1. 选帧：`python scripts/select_cover_frame.py <源片> --times <秒,...>`（或 `--samples 14`）
   → 打分行只筛"有信息量、不过黑过曝"的帧；**必须再逐帧识图复核**（女主颜值/姿态/标题留白），人工确认最佳帧。
   识图走本机 dabao-vision 链路（vision_analyze，或直连 DeepSeek 原生读图绕开 OCR 路由）。
2. 导出底图：`ffmpeg -ss <秒> -i <源片> -frames:v 1 -q:v 1 <片目录>\封面\封面底图-主推.jpg`
3. 生成提示词：`python scripts/gen_jimeng_cover_prompts.py --movie <片名> --out <片目录>\封面\封面提示词-即梦.txt`
4. 用户操作：即梦 → 图生图 → 上传底图 → 选 3:4 / 4:3 → 粘贴对应提示词 → 出图。
   - 文字出错：局部重绘文字区 / 换种子重生成；实在不行让即梦出无字图，标题改由剪辑软件后期加。
5. 发布信息：写 `<片目录>\发布信息.txt`（片目录根或 `发布\` 子目录都认，脚本递归扫描；第一行标题 ≤25 字，
   第二行恰好 5 个话题词，惯例带频道词 `#艾伦和艾薇`）。多平台各留一份时整文件放 N 块（每块两行，可空行分隔），跑
   `python scripts/validate_publication_info.py <片目录> [--blocks N]` 校验通过后才算交付。

## 坑（实测）

- **底图决定上限**：女主不在画面/太暗/糊的帧，即梦救不回来多少；优先亮且清晰的帧。
- 即梦对中文手写大字偶有错字，提示词已固定"无错字无变形"，出图后必须人工核对那四个字。
- 参考图里的大块杂物（门牌、字幕条、其他人）会渗进成图——选帧时避开，或出图后局部重绘。
- 提示词里「」只用于标注文字；若成图把引号也画出来，把提示词中对应引号删掉重试。
- 发布信息标题不要用「·」（写成 杰米李柯蒂斯），否则顶掉字数上限。
- 发布信息用户会自己改写再发（2026-09 实测版：「毕业舞会变猎场！尖叫女王柯蒂斯尖叫首秀」——标题不用《片名》、
  直接上钩子；话题词固定含 `#艾伦和艾薇`）——我们出初稿供改即可，不要锁死格式。
